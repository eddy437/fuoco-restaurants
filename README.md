# Fuoco Restaurants

Welcome to the Fuoco Restaurants API documentation.

## Overview
This API provides access to restaurant data including listing, creation, and management of restaurant information.

## Getting Started

To get started with the Fuoco Restaurants API, you will need to authenticate your requests and understand the endpoints available.

## Endpoints

- `GET /restaurants` - Retrieve a list of all restaurants.
- `POST /restaurants` - Create a new restaurant.
